# Astra — App Horoscope IA Francophone

MVP React + Vite. Horoscopes générés en temps réel par Claude API.

## Lancer en local

```bash
npm install
npm run dev
```

## Stack

- React 18 + Vite
- Claude API (claude-sonnet-4-20250514)
- CSS inline (design tokens)

## Prochaines étapes (Cursor)

- Supabase auth + profils utilisateurs
- Stripe abonnement
- PWA / notifications push
